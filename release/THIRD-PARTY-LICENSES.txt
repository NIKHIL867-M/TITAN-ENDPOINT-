8. Windows Operating System APIs
================================================================================

The TITAN ENDPOINT native endpoints use publicly documented Windows APIs including:
  - Windows Event Tracing (ETW)
  - Windows Filtering Platform (WFP)
  - SetupAPI and Device Notification
  - Winsock2
  - Win32 Process/Job/Token APIs
  - Windows CryptAPI (BCrypt)

These APIs are part of the Windows SDK and are governed by the
Microsoft Windows SDK License Agreement. Their use does not impose
third-party license obligations on TITAN ENDPOINT beyond the Windows SDK EULA.

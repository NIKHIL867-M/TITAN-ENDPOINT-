HOW TO READ THIS FILE
----------------------
6 independent, native C++20 Windows programs, each its own CMake project,
zero shared library between them (each duplicates small shared patterns —
collector_health, resource_pressure.h, t_unix_ms — rather than linking a
common lib). 5 are sensors; the 6th (Correlator) only ever READS the other
5's output logs and never writes into them.

  [Box]      = a running process / program
  (Module)   = a source file / component inside a program
  ─▶         = data flows in this direction
  ⇒          = "produces / writes to"
  ⇐          = "reads / tails"

CROSS-CUTTING CONCERNS (present in ALL 6 programs, each its own duplicated copy):

  • collector_health   — periodic JSON record: status, loss/drop counters,
                          "resource_pressure" tier. Every program emits one.
  • t_unix_ms           — UTC epoch-ms integer on every JSON record; the
                          Correlator's join key (added Round 2).
  • resource_pressure.h — GlobalMemoryStatusEx + GetDiskFreeSpaceExW sampled
                          every 15-30s ⇒ Normal/Lightened/Severe tier ⇒
                          shrinks each program's own log-retention cap.
                          NEVER shrinks WHAT is captured, only HOW LONG
                          evidence is kept on disk.
